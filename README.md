# 🎬 Full Stack IMDB Clone

A full-stack movie web application built from scratch using **React**, **TMDB API**, and optionally **Node.js/Express** for backend. It allows users to browse, search, and manage a watchlist of movies with sorting, filtering, and pagination features.

## 🛠️ Features

- 🎞️ Browse popular movies using TMDB API
- 🔍 Search movies by title
- 📄 Pagination & sorting
- 🌟 Watchlist (stored in LocalStorage)
- 🔁 Filter by genres
- 📱 Responsive UI
- ⚙️ React Router & Dynamic Routing
- 🌐 Deploy-ready CI/CD setup with GitHub Actions
